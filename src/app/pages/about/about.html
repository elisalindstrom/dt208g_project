Om webbplatsen

På denna sida kan du läsa om hur Norruniversitetet hanterar kakor, personuppgifter och tillgänglighet.

Kakor (cookies)

Kakor är små textfiler som kan lagras på din dator när du besöker en webbplats.

Norruniversitetet använder lokal lagring för att spara användarens kursschema mellan besök. Du kan när som helst välja att blockera eller radera kakor via inställningarna i din webbläsare.

Personuppgifter

Om du kontaktar Norruniversitetet via e-post kan de uppgifter du lämnar användas för att hantera ditt ärende. Webbplatsen samlar inte in några personuppgifter.

Tillgänglighet

Norruniversitetet arbetar kontinuerligt med tillgänglighet och strävar efter att alla ska kunna använda webbplatsen.

Om du upptäcker brister med tillgängligheten kan du kontakta oss på: info@norruni.se
